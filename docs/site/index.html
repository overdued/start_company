KunPeng-Hermes Fusion

全球首个在 ARM64 嵌入式平台上实现「硬件控制 + 大模型 + 自进化学习 + 视觉识别 + 声纹识别 + 语音交互」六维融合的 AI 智能体

v2.2 🆕 声纹识别 🆕 语音交互 MIT 开源

产品定位

KunPeng-Hermes Fusion 运行在 OrangePi Kunpeng Pro (RK3588) 上，融合 KunPeng-Cortex 硬件控制 与 Hermes Agent 自进化学习，打造"会学习的硬件控制智能体"。


核心场景：居家养老 — 轮足机器人搭载传感器和摄像头，实时监测老人健康状态，AI 语音陪伴、智能提醒用药、跌倒检测、视觉巡检。

核心能力

🎤

声纹识别

CAM++ 192 维声纹向量，识别"谁在说话"。四通道麦克风采集，支持家庭多人场景。阈值 0.35 验证，25-35 待定池机制。

🗣️

全双工语音

sherpa-onnx KWS 唤醒词"小鲲小鲲/你好小鲲"（拼音模糊匹配）+ SenseVoiceSmall ASR + edge-tts 自然语音播报。完整 VAD→KWS→ASR→对话→TTS 闭环。

📷

视觉识别

真实 USB 摄像头拍照 + Kimi k2 多模态 AI 描述。绝对禁止编造——所有路径和描述均来自真实硬件执行结果。

🧠

自进化 Skill

每次硬件操作自动学习，生成可复用 SKILL.md。重复任务 2-3x 加速，Token 消耗降低 60%。3 个预设 Skill（取药/跌倒/灯光）。

📋

Memos 笔记

用户对话自动分类/打标签/生成画像。health/用户偏好/紧急/客户需求 8 种分类。离线 SQLite 存储，有网可同步 Memos 服务器。

🔧

硬件控制

GPIO / I2C / UART / PWM / Camera 全栈 HAL。机械臂（6-DOF）、超声波、陀螺仪、ESP32/STM32 桥接。物理安全层：MCU 紧急停止。

产品形态

🤖

轮足机器人

状态：官网展示，硬件组装待排期

橘派 RK3588 搭载于轮足机器人平台，通过 UART 连接 RT1064 MCU 控制双电机。支持前进/后退/转向/停止。TOOL_DEFINITIONS 已预留 control_car / control_arm 工具钩子。

控制链路：App → WebSocket :8765 → 橘派 → UART → RT1064 → 电机

📱

Android App

OctopusController v1.0.1

Kotlin 原生 WebView 套壳，离线 Mock 模式 + 香橙派 WebSocket 模式。最低 Android 6.0，横屏触控。局域网或互联网连接橘派。

内置：电机控制、对话聊天、提醒管理、健康数据、紧急呼叫

🖥️

桌面宠物

pywebview + FastAPI 隐私安全 HMI

浏览器访问橘派 IP:8765/companion 即见"小鲲桌宠"。Windows/Mac/Linux 均可。桌宠进程不接触 API 密钥（凭据隔离）。

表情：neutral/warm/caring/uncertain — 低打扰陪伴策略

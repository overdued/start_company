# hengxiang.HMI — 横屏 HMI 设计方案

## 一、基本信息

| 项目 | 参数 |
|------|------|
| 文件名 | hengxiang.HMI |
| 屏幕分辨率 | **800 × 480**（横屏） |
| 串口波特率 | 115200 bps |
| 数据格式 | 8N1 |
| 协议模式 | 0（字符串指令） |
| 页面数量 | 6 |

## 二、页面总览

| 页面ID | 名称 | 功能 | 触发方式 |
|--------|------|------|---------|
| 0 | boot | 启动加载 | 上电自动 |
| 1 | home | 首页仪表盘 | 加载完成 / 导航 |
| 2 | chat | AI 对话 | 底部导航 / 按钮 |
| 3 | remind | 提醒与健康 | 底部导航 / 按钮 |
| 4 | device | 家居控制 | 底部导航 / 按钮 |
| 5 | setting | 系统设置 | 底部导航 / 按钮 |

## 三、全局设计规范

### 3.1 色彩体系（暖色主题）

| 用途 | 色值 | 说明 |
|------|------|------|
| 页面背景 | #FDF6EE | 暖杏色 |
| 卡片背景 | #FFF8F0 | 比页面稍白 |
| 主色调 | #C4873A | 焦糖金 |
| 正文字 | #2C2416 | 深棕 |
| 辅助字 | #8C7A5E | 浅棕 |
| 分割线 | #F0EBE0 | 极浅棕 |
| 成功/在线 | #5A8A5A | 草绿 |
| 警告 | #C4A03A | 暗黄 |
| 危险/紧急 | #C44A4A | 暗红 |

### 3.2 字体规范

| 用途 | 字号 | 字体 |
|------|------|------|
| 页面标题 | 24px | 黑体 |
| 大数值（温度等）| 28px | Arial Bold |
| 正文内容 | 16px | 黑体 |
| 辅助说明 | 12px | 黑体 |
| 按钮文字 | 14px | 黑体 |
| 底部导航 | 10px | 黑体 |

### 3.3 布局区域（800×480）

```
┌──────────────────────────────────────────────────┐
│  状态栏 (0,0 → 800,24)                           │  y: 0-24
├──────────────────────────────────────────────────┤
│                                                  │
│  内容区域 (0,24 → 800,436)                       │  y: 24-436
│  (每个页面的具体内容)                              │  高 412px
│                                                  │
├──────────────────────────────────────────────────┤
│  底部导航栏 (0,436 → 800,480)                    │  y: 436-480
└──────────────────────────────────────────────────┘
```

- **状态栏**：时间 + WiFi + 小鲲状态，全局共享，每个页面顶部固定
- **底部导航**：5 个 tab（首页/会话/提醒/家居/设置），全局共享，每页底部固定
- **内容区域**：412px 高度，每个页面的核心内容

**说明**: Nextion 屏幕不支持真正的文字气泡和自动滚动，所以消息区用 7 个固定 text 组件模拟。MCU 每次收到新消息后，整体往上"滚动"：msg1=msg2, msg2=msg3, ... msg7=新消息。

**MCU → 屏幕（新消息到达）**:
```
// 向上滚动：复制内容
t_msg1.txt=t_msg2.txt
t_msg2.txt=t_msg3.txt
t_msg3.txt=t_msg4.txt
t_msg4.txt=t_msg5.txt
t_msg5.txt=t_msg6.txt
t_msg6.txt=t_msg7.txt

// 设置最新消息
t_msg7.txt="好的，客厅灯已经帮您打开了"
t_msg7.pco=43947    // AI 消息颜色

// 用户消息用不同颜色
t_msg7.pco=16777215  // 白色(用于深色背景气泡) 或 #C4873A
```

**按钮事件**:

| 组件 | ID | 帧 | 动作 |
|------|-----|-----|------|
| b_voice | 13 | `65 02 0D 01 FF FF FF` | 开始录音 |
| b_send | 15 | `65 02 0F 01 FF FF FF` | 发送消息 |

## 五、全局串口协议汇总

### 5.1 帧格式

所有指令以 `FF FF FF` 三字节结尾。

**触摸事件帧（屏幕 → MCU）** — 7 字节：
```
[65] [页面ID] [组件ID] [01按下/00抬起] [FF] [FF] [FF]
```

**显示更新指令（MCU → 屏幕）** — 字符串：
```
组件名.属性=值\xFF\xFF\xFF
```
